# Unconventional_Growth_Kinetics_Fractal_Interfaces_of_Colloidal_Phase_Separation_in_Active_Liquids

This repository contains the data required to interpret, verify, and extend the research in the article, as well as all the simulation codes for simulating the field theory model presented in the manuscript.

The organization of the data and code is described below.


**###-------### Organization of Data and Plotting Scripts**
The data for the different figures are stored in the "Manuscript_data" folder. Within this folder, the data corresponding to the figures in the main manuscript are organized according to their respective figure numbers in the "Main_Manuscript_data" folder. Similarly, the data corresponding to the figures in the Supplementary Information are organized according to their respective figure numbers in the "Supplementary_Information_data" folder.

The plotting scripts used to generate the figures in the main manuscript and the Supplementary Information are provided in their respective folders.


### Organization of Simulation Codes

The codes used to simulate the field-theory model and generate the data presented in the manuscript are organized in the `Simulation_codes` folder.

The field-theory framework models the effects of active particles on passive colloidal particles in an active–passive mixture. The influence of the active particles on the passive particles is represented by a spatiotemporally correlated colored noise.

The theoretical background for generating the spatiotemporally correlated colored noise is described in the following reference:

https://journals.aps.org/pra/abstract/10.1103/PhysRevA.46.4670

The simulations are implemented in **Fortran 77**. The spatiotemporally correlated colored noise is generated by solving a reaction–diffusion equation. A Gaussian white-noise field is first generated using the standard `gasdev` subroutine from *Numerical Recipes in Fortran 77* and is then filtered to obtain the desired spatiotemporal correlations.

### Included Codes

**(i) `snapshot_code.f`**
Generates snapshots of the evolving $\phi$-field for producing figures and animation movies for the manuscript. In the provided code, the parameters are set to a correlation length `alam = 7` and a correlation time `at = 1` for the colored noise. These parameters can be varied to generate the different datasets included in the manuscript.

**(ii) `correlation_code.f`**
Computes the two-point correlation function and the structure factor of the $\phi$-field using the Hartree variable and Fast Fourier Transform (FFT) methods. In the provided code, the parameters are set to a correlation length `alam = 7` and a correlation time `at = 1` for the colored noise. These parameters can be varied to generate the different datasets included in the manuscript.

### Instructions for Running the Codes

#### (i) Compiling the Codes

The codes can be compiled using:

```text
gfortran code_name.f -o code.exe
./code.exe
```

#### (ii) Data Generated by `snapshot_code.f`

Before running the code, the file `fnameapol` should be placed in the same folder as the source code.

After compilation and execution, files named `apo.i` (`i = 1, ..., Nsnap`) are generated, where `Nsnap` is the number of snapshots.

The data in each file are stored in three-column format:

```text
x    y    φ(x,y)
```

Here, $(x,y)$ denote the locations of the lattice points, and $\phi(x,y)$ is the value of the field $\phi$ at the corresponding lattice point.

The generated data can be plotted as a heatmap using Gnuplot, Python, MATLAB, or other plotting software.

#### (iii) Data Generated by `correlation_code.f`

After compilation and execution, the following files are generated:

* `cf.i` (`i = 1, ..., 20`): Two-point correlation function $c(r)$ versus $r$ at different times.
* `sf.i` (`i = 1, ..., 20`): Structure factor $S(k)$ versus $k$ at different times.
* `lens.dat`: Characteristic length obtained from the structure factor as a function of time.
* `lenc.dat`: Characteristic length obtained from the correlation function as a function of time.
